RECALL OBJECT

openFDA

One GET for the recall event. All rows that share its event_id are merged into one recall.

Cala

Looks up the recalling company. A fuzzy hit only counts if the name truly matches, so “GIAS FOOD” is not mistaken for another firm.

Krea

Four image jobs run in parallel: hazard, product, kitchen, statement background. Prompts forbid any text in the image.

Local steps

Copy is filled from templates, then Chrome lays real HTML text over each image and saves 1080×1080 PNGs.

This is a replay of two real runs of npm run generate. Recall data, Cala results, Krea images and cards are the actual outputs. Waiting times are compressed: a live run spends most of its time waiting on Krea jobs.
